# Ai-rent-prediction-Project


supervised machine learning regression project that predicts monthly apartment rent using the UCI Apartment for Rent Classified dataset. The project uses apartment listing features such as bedrooms, bathrooms, square footage, location, amenities, and other rental details to estimate rent prices.
The workflow includes data cleaning, missing value handling with median imputation, one-hot encoding for categorical features, feature extraction, model training, evaluation, and visualization. Three regression models were trained and compared: Linear Regression, Random Forest Regressor, and Gradient Boosting Regressor.
Random Forest performed the best based on MAE, RMSE, and R² score. The project also includes feature importance for explainable AI and an interactive Colab widget interface where users can enter apartment details and receive a predicted rent estimate.
